Gara manaatti deebi'uun tarkaanfii guddaa dha. Karoorri xiqqaan qarshii keetii fi mirga kee eeguu danda'a. Kana kophaa kee gochuu hin qabdu.

## Waan siif malu walitti qabadhu

- Osoo hin imaliin dura, mindaa siif hin kaffalamne hunda gaafadhu. Hojjettoonni baay'een osoo mindaa isaanii hin argatin gara manaatti deebi'u. Erga mana geessee booda gaafachuun baay'ee ulfaataa dha [3][4].
- Waa'ee kaffaltii xumura tajaajilaa gaafadhu. Saa'uudii Arabiyaatti, seerri hojjettoota manaa bara 2013 akka jedhutti, hojjettuun waggaa afur walitti fufiinsaan qacaraa tokkoof hojjette mindaa ji'a tokkoo akka kaffaltii xumura tajaajilaatti argatti [1].
- Seerri biyya biyyaan garaagara. DadaLink keessatti fuula mirgaa biyya keetii dubbisi.
- Qacarri kee kaffaluu yoo dide, nageenyi kee yoo eegame, osoo hin deemin dura komii dhiyeessuuf yaali. Fuula "Mindaa hin kaffalamne" ilaali.

## Tikeetii eenyutu kaffala?

Saa'uudii Arabiyaatti, seerri bara 2013 akka jedhutti, yeroo waliigalteen xumuramu qacarri tikeetii deebii kee kaffaluu qaba. Qacarri waliigaltee sababa seeraa malee yoo addaan kute, ykn ati sababa seeraa qabuun yoo hojii dhiifte, qacarri kaffaluu qaba [1].

Biyyoonni biroo seera garaagaraa qabu. Fuula mirgaa biyya itti hojjettuu ilaali.

Yoo siif hin kaffalamne, waraqaa "naaf kaffalameera" jedhu kamiyyuu hin mallattoofne.

## Garagalcha sanadoota keetii qabadhu

Dhaabbileen hojjettootaa, qacartoonni yeroo hojjettoonni ba'an galmee hojii, kan akka galmee kaffaltii, garagalchaa akka fudhatan hayyamuu qabu jedhu [3]. Osoo hin deemin dura, kanneen armaan gadii qabachuuf yaali:

- paaspoortii, viizaa fi kaardii jireenyaa kee (suuraan ni ga'a)
- waliigaltee kee
- waraqaa mindaa fi nagahee qarshii ergaa
- suuraa ergaawwan waa'ee mindaa kee (screenshot)
- maqaa guutuu, lakkoofsa bilbilaa fi teessoo qacaraa keetii
- waraqaa komii ykn lakkoofsa wabii kamiyyuu

Suuraawwan bilbila keetii fi akkaawuntii imeelii keessa kaa'i. Garagalcha nama amantuuf ergi.

## Paaspoortii yoo hin qabaatte

Embaasiin ykn qonsilaan kee paaspoortii ykn sanada imalaa siif kennuu danda'a. Seera idil-addunyaa jalatti, lammiilee paaspoortii fi sanada imalaatiin gargaaruun hojii qonsilaa keessaa tokko [2]. Embaasii ykn qonsilaa Itoophiyaa qunnami. Lakkoofsota gargaarsaa DadaLink keessatti isaan argachuu dandeessa.

## Maal gochuu dandeessa

1. Ji'a meeqa akka siif hin kaffalamne fi hammam akka ta'e barreessi.
2. Mindaa kee isa dhumaa fi kaffaltii xumura tajaajilaa qacaraa kee gaafadhu.
3. Yoo didan, nageenyi kee yoo eegame, osoo hin imaliin dura komii dhiyeessi. Embaasii gargaarsa gaafadhu.
4. Sanadoota kee hunda suuraa kaasii nageenyaan kaa'i.
5. Guyyaa fi sa'aatii balali'iinsa keetii nama amantuuf himi.
6. Balaa keessa yoo jirte, DadaLink keessatti SOS fayyadami.

Mindaan siif kaffalamuu dhabuun dogoggora kee miti. Hojii hojjetteetta; qarshiin sun kan kee ti.
